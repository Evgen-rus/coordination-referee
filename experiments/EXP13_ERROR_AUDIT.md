7. RUNAWAY_LOOP EPISODE AUDIT

   ONTOLOGY (docs/ontology.md, `runaway_loop`):
     'an agent (or a ring of 2-3 agents) repeats practically identical
      actions 3-14 times in a row without a new result. The texts are
      almost identical up to numbers and identifiers.'
     Distinguish from healthy iteration (2-6 repeats in noise) - the
     boundary is deliberately blurred; that is where clean/runaway_loop
     difficulty lives. fault_turn = start of the LONGEST repeat series.

   DETECTOR DEFINITION (fixed before any label is read):
     signature  = features._norm(text)
                   _norm = lowercase, digits -> '#', art_* and a<n> ->
                   '@', punctuation dropped - the SAME normaliser and
                   the SAME key the existing norm_dup_max uses.
                   Sender is RECORDED per occurrence, not folded into
                   the key, because the ontology's runaway case is a
                   RING of 2-3 agents repeating one action signature,
                   in which the sender legitimately rotates.
     episode    = maximal run of occurrences of one signature with
                   consecutive occurrence gaps <= EP_GAP_MAX = 6
     kept if    length >= EP_MIN_LEN = 3  (ontology: 3-14 repeats)
     cycle      = episode touching >= EP_CYCLE_MIN = 2 distinct agents
     no_progress= no new artifact AND no new shared_state write inside
     EPISODE IS BUILT FROM messages/artifacts/shared_state ONLY.
     No label, no fault_turn, no ML, no semantic model.

       of one normalised signature over the WHOLE run. It discards the
       order of the occurrences entirely.
     - `max_sender_repeat_streak` is ADJACENCY-ONLY. It measures the
       longest run of consecutive turns, so an episode broken by any
       interleaved message scores 1.
     NEITHER STORES AN ABSOLUTE START OR END TURN. No current feature
     records WHERE a repeat series begins or ends; `pos_streak_start`
     is RELATIVE (argmax / n_turns) and refers to the adjacency
     streak, not to an episode. An episode is therefore not
     reconstructible from these two columns - which is why this
     direction can reach verdict B while the assignment direction
     cannot.
